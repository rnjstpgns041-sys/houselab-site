성남 오래된 싱크대 수도 수전 철거 후 새 제품 설치 과정

작업 전
처음 확인했을 때에는 기존 수전이 싱크볼 중앙에 설치되어 있었습니다. 수전에는 인출식 호스가 연결되어 있었지만 고장이 발생해 정상적으로 사용하기 어려운 상태였습니다.
작업 내용
기존 수전 상태 확인 → 하부 급수 연결부 확인 → 기존 수전 철거 → 새 수전 설치 → 급수 연결 및 최종 점검
작업 완료
작업 전에는 기존 수전의 고장으로 인해 물을 사용하는 데 불편함이 있었습니다. 기존 제품을 철거하고 새 수전으로 교체하면서 싱크볼에서 다시 편하게 물을 사용할 수 있게 되었습니다.
마무리
수전은 매일 사용하는 설비인 만큼 작동이 뻑뻑하거나 호스가 손상되고 연결부에서 물이 보인다면 불편한 상태로 계속 사용하기보다 원인을 확인해보는 것이 좋습니다.

BEFOREAFTER

서울 강남 세탁기 위 건조기 철제 프레임 설치

작업 전
처음 방문했을 때에는 세탁기 한 대만 세탁실 안쪽에 놓여 있었습니다. 세탁기 위쪽은 비어 있었지만 뒤쪽에는 보일러가 있고 옆에는 급수 배관과 호스, 바닥에는 배수구가 있었습니다.
작업 내용
세탁실 구조 확인 → 제품 크기 확인 → 철제 프레임 조립 → 상판 설치 → 건조기 이동 및 설치
작업 완료
작업 전에는 세탁기 위쪽 공간을 활용하지 못하고 있었습니다. 철제 프레임과 상판을 설치한 뒤 건조기를 위쪽으로 올리면서 좁은 세탁실 안에서도 세탁기와 건조기를 상하로 함께 사용할 수 있게 되었습니다.
마무리
또 건조기가 세탁기 위에 직접 올라가는 것이 아니라 별도의 프레임이 무게를 지지하도록 만들어 두 제품이 서로 맞닿지 않도록 했습니다.

BEFOREAFTER

서울 강동 주방 슬라이딩 양념장 맞춤 제작

작업 전
현장을 확인해 보니 싱크대 하부장 사이에 양념장이 빠진 공간이 있었습니다. 기존 슬라이딩 양념장이 있던 자리에는 레일과 내부 구조 일부가 남아 있었고 전면 마감도 없는 상태였습니다.
작업 내용
주방 하부장 구조 확인 → 양념장 설치 공간 실측 → 슬라이딩 양념장 제작 → 레일 및 수납장 설치
작업 완료
이번 현장에서 가장 크게 달라진 부분은 비어 있던 공간을 다시 활용할 수 있게 되었다는 점입니다. 기존에는 양념장이 파손되어 하부장 사이가 비어 있었지만 새로운 슬라이딩 양념장을 제작하면서 수납 기능을 되살렸습니다.
마무리
전체 싱크대를 교체하지 않고 필요한 부분만 맞춤 제작해 기존 주방을 활용했다는 점이 특징입니다.
