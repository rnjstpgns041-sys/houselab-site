서울 송파 벽걸이 미니 세탁기 철거·벽면 복원

작업 전
처음 현장을 확인했을 때 미니 세탁기가 벽면에 고정되어 있었습니다. 제품 뒤쪽에는 여러 개의 앙카볼트가 벽체 깊숙하게 고정되어 있어 제품을 분리한 이후에도 볼트가 그대로 벽에 남는 구조였습니다.
작업 내용
미니 세탁기 설치 상태 확인 → 미니 세탁기 분리 및 철거 → 벽면 앙카볼트 제거 → 타공 구멍 메움 작업
작업 완료
이번 작업은 미니 세탁기 철거와 함께 철거 후 남는 흔적까지 정리한 작업입니다. 벽걸이 가전은 철거하고 나면 고정에 사용했던 앙카와 여러 개의 타공 자국이 남을 수 있습니다.
마무리
제품만 제거하고 끝내는 것보다 앙카 제거와 구멍 메움까지 함께 진행하면 사용하지 않는 벽면을 훨씬 깔끔하게 정리할 수 있습니다.

BEFOREAFTER

서울 송파 변기 하부 고정 시멘트 보수

작업 전
현장을 확인해 보니 변기와 바닥이 만나는 부분을 따라 기존 시멘트가 갈라져 있었습니다. 일부는 이미 떨어져 나가 있었고 손상된 부분은 작은 충격에도 추가로 부서질 수 있는 상태였습니다.
작업 내용
변기 하부 상태 확인 → 깨진 고정 시멘트 제거 → 바닥과 변기 주변 정리 → 수평과 위치 확인 → 새 고정재 시공 및 마감
작업 완료
작업 전에는 변기 아래의 기존 시멘트가 여러 부분 깨져 고정부가 불안정한 상태였습니다. 이번 작업에서는 손상된 기존 재료를 먼저 제거하고 수평과 위치를 확인한 뒤 하부를 새롭게 고정했습니다.
마무리
다만 변기가 실제로 심하게 흔들리거나 누수까지 함께 발생한다면 하부 배관과 정심 상태까지 추가 확인이 필요할 수 있습니다.

서울 송파 식기세척기 급수 밸브 교체

작업 전
작업 전에는 식기세척기 급수호스가 연결되는 급수 밸브 부분이 파손되어 정상적으로 사용하기 어려운 상태였습니다.
작업 내용
작업 준비 → 싱크대 하부 급수 배관 확인 → 파손된 급수 밸브 점검 → 새 급수 밸브 설치 → 식기세척기 급수호스 연결
작업 완료
작업 완료 후에는 기존 배관 상태를 확인한 뒤 식기세척기 전용 급수라인에 새로운 밸브를 설치했습니다.
마무리
마지막으로 식기세척기를 작동시켜 정상적으로 급수가 이루어지는 것까지 확인한 후 작업을 마무리했습니다.

작업 전
작업 전에는 냉장고 위쪽에 2도어 상부장이 설치되어 있었고 기존 냉장고와 상부장 사이에는 일정한 여유 공간이 있었습니다.
작업 내용
냉장고장 상부장 철거 → 상부장 하단 절단 작업 → 절단면 마감 및 리폼 → 상부장 재설치 → 최종 점검 및 작업 완료
작업 완료
