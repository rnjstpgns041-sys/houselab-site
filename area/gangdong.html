서울 강동 주방 슬라이딩 양념장 맞춤 제작

작업 전
현장을 확인해 보니 싱크대 하부장 사이에 양념장이 빠진 공간이 있었습니다. 기존 슬라이딩 양념장이 있던 자리에는 레일과 내부 구조 일부가 남아 있었고 전면 마감도 없는 상태였습니다.
작업 내용
주방 하부장 구조 확인 → 양념장 설치 공간 실측 → 슬라이딩 양념장 제작 → 레일 및 수납장 설치
작업 완료
이번 현장에서 가장 크게 달라진 부분은 비어 있던 공간을 다시 활용할 수 있게 되었다는 점입니다. 기존에는 양념장이 파손되어 하부장 사이가 비어 있었지만 새로운 슬라이딩 양념장을 제작하면서 수납 기능을 되살렸습니다.
마무리
전체 싱크대를 교체하지 않고 필요한 부분만 맞춤 제작해 기존 주방을 활용했다는 점이 특징입니다.

서울 강동 들뜬 거실 벽타일 재부착

작업 전
작업 전에는 벽면 전체가 정상적으로 시공된 것처럼 보였지만 확인해보니 여러 장의 타일이 벽면에서 들떠 있었습니다. 이 상태를 그대로 두면 들뜸이 심해지면서 타일이 떨어지거나 파손될 가능성이 있습니다.
작업 내용
들뜬 타일 상태 확인 → 기존 타일 조심스럽게 철거 → 타일과 벽면 정리 → 접착제 보강 후 재부착
작업 완료
작업 전에는 일부 타일이 들떠 있어 추가 탈락이나 파손이 걱정되는 상태였습니다. 들뜬 타일을 철거한 뒤 기존 타일을 다시 부착하면서 벽면을 원래 모습으로 복원했습니다.
마무리
특히 기존 타일을 재사용해 새로운 타일을 부분적으로 넣었을 때 생길 수 있는 색상과 무늬 차이도 줄일 수 있었습니다.

작업 내용
빌트인 냉장고 설치 상태 확인 → 주변 가구와 고정 부위 확인 → 냉장고 본체 철거 → 이동 동선 확보 및 외부 반출 → 폐기 및 철거 공간 최종 확인
작업 완료
